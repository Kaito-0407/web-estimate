# 週1の自動更新手順（aidev.k-web-lab.com）

報告は日本語・結論から。確認していないことは「未確認」と書く。根拠（URL・コマンド出力）を添える。

## 1. 料金の照合（毎回）
1. https://platform.claude.com/docs/en/about-claude/pricing を取得し、`js/prices.js` の Claude 各モデル（入力・出力・キャッシュ読み込み、Haiku 5.5 の10万トークン超の料金、バッチ割引）と照合する
2. https://platform.openai.com/docs/pricing の標準・短いコンテキストの表と OpenAI 各モデルを照合する
3. 為替：`https://api.frankfurter.dev/v1/latest?base=USD&symbols=JPY` の値と日付で `FX` を更新する
4. 新モデルが出ていれば追加、廃止されていれば削除。変更したら `PROVIDERS.*.checked` を今日の日付にする
5. ガイド `guide/claude-api-pricing.html` の表と月額例も `js/cost.js` で計算し直して合わせる（手計算しない）

## 2. ROADMAP の先頭を1つ進める
- 事実は公式ドキュメントだけを根拠にし、記事内に出典URLと確認日を書く
- 新しいページは `sitemap.xml` と `deploy.sh` のコピー対象、`tests/check.mjs` / `tests/live.cjs` のページ一覧に追加する

## 3. 確認と公開
1. `node tests/check.mjs` がすべてOK（失敗したら直す。テストを消したり緩めたりしない）
2. `tests/out/` のスクリーンショットを全部開いて目で確認する（見切れ・重なり・崩れ）
3. `./deploy.sh`（チェック→版番号付け→Cloudflare Pages→IndexNow）
4. `node tests/live.cjs` で本番を確認
5. コミットして main に push

## 4. 報告
変更点、照合結果（変わった単価があれば旧→新）、本番確認の結果、未確認の点。
